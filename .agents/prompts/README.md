# Промты для типовых задач

Каждый файл содержит **два варианта** путей:

| Вариант | Когда использовать | Пример пути |
|---------|-------------------|-------------|
| **A — субмодуль в проекте** | ai-sdlc-rules подключён как `.agents/` | `.agents/AGENTS.md` |
| **B — запуск из ai-sdlc-rules** | агент запущен прямо в папке ai-sdlc-rules | `AGENTS.md` |

## Полный цикл разработки

| Файл | Задача |
|------|--------|
| `architecture.md` | Написать архитектурный документ до реализации |
| `feature.md` | Реализовать новую фичу |
| `bugfix.md` | Исправить баг |
| `hotfix.md` | Срочный фикс в прод |
| `refactoring.md` | Рефакторинг без изменения поведения |
| `tests-unit.md` | Написать юнит-тесты |
| `tests-integration.md` | Написать интеграционные тесты |
| `code-review.md` | Провести code review |
| `mr.md` | Подготовить описание Merge Request |
| `commit.md` | Сделать коммит по правилам |
