# AGENTS.md

Проект работает по правилам из `.agents/`.

Перед любой реальной работой прочитай:

1. `.agents/AGENTS.md` — главные правила проекта: язык общения, commit-теги,
   error-handling, ветки, реакция на падение проверок.
2. `.agents/CLAUDE.md` — карта правил, skills и prompts.

Дальше выбери релевантные файлы из `.agents/agents/` и `.agents/skills/` под тип задачи:
feature, bugfix, hotfix, refactoring, tests, code-review, MR или docs.

Не начинай менять код, пока не прочитал эти правила.
